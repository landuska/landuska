### 📚 BookDiaryApp — AI-Powered Book Library Platform
An AI-powered book management platform built with Flask, PostgreSQL, LangGraph, and OpenAI.
The application combines personal library management with a personalized AI reading assistant using Retrieval-Augmented Generation (RAG).

- **AI Assistant:** Built a conversational AI agent using LangGraph and OpenAI with user-specific conversation threads and tool-based reasoning
- **RAG Pipeline:** Implemented semantic search using OpenAI embeddings and FAISS vector search over users’ reading history, ratings, and personal notes
- **Personalization:** Generated structured AI taste profiles based on user preferences and feedback to provide personalized recommendations
- **Agent Tools:** Integrated tools for user reading profiles, semantic search, book information retrieval, and movie adaptation search
- **Backend Architecture:** Developed a Flask application with SQLAlchemy ORM, PostgreSQL database, authentication, and modular service layers
- **Features:** Personal library management, book search, AI-generated summaries, reading communities, author management, and AI chat assistant
- **Tech:** Python 3, Flask, SQLAlchemy, PostgreSQL, LangGraph, OpenAI API, FAISS, Embeddings, Google Books API, Jinja2
